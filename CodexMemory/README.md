# Llama Harness memory

This folder is the Markdown vault for Llama Harness decisions and notable runs. It can be opened as an Obsidian vault; Obsidian is optional and the files remain ordinary Markdown.

Keep application-specific decisions and sensitive project context in the owning project. Do not copy credentials, private data, or full chat transcripts here.

Start at [INDEX](INDEX.md). The workspace workflow is in [workflow](workflow.md). An ADR records a durable decision; a run record captures a significant piece of work and its evidence.
