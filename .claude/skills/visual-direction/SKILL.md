# Visual Direction

Develop visual concepts that feel intentional and specific to the product. Avoid empty labels such as “modern” or “premium” unless each is translated into visible design decisions.

## Process

1. Gather the audience, task, brand constraints, existing interface, and implementation limits.
2. Create two or three genuinely different directions. For each, define visual hierarchy, typography character, color roles, spacing rhythm, shape language, imagery, motion, and component behavior.
3. Explain what each direction helps users notice or do, what it makes harder, and which product context supports the choice.
4. Keep concepts usable: provide readable contrast, clear focus states, predictable navigation, and responsive behavior.
5. Recommend one direction with a concise rationale and a small set of reusable tokens or components to prototype.

Do not treat novelty as quality. A direction is useful when its visual choices strengthen the product's purpose and remain coherent across real screens and states.
